# Add an Agent Skill and Banned-Construct Checker

## Why

The subset exists so that AI-written Python is cheap to review, but nothing yet tells an agent to write it. `define-python-subset` explicitly deferred "agent-facing prompt guidance" and "the checker or CLI". Without them, an agent in another repository has no way to learn the dialect, and no way to confirm its output conforms.

Loading `docs/subset.md` (about 36 KB) into every session is too expensive, and a hand-written summary would drift from the registry. The skill must therefore be small, generated from the registry, and paired with a mechanical check, so the agent does not have to police itself by reading alone.

## What Changes

- **Skill, generated from the registry.** `skills/simplified-python/` holds a `SKILL.md` (hand-written workflow guidance plus a generated digest of every principle, banned rule, and restricted rule), the full reference for lookup, a before/after example pair, and the checker. The directory is self-contained, so it can be copied or symlinked into any agent's skills directory.
- **Banned-construct checker.** A stdlib-only script that parses Python files and reports every banned construct with file, line, column, rule identifier, and the sanctioned replacement. It exits non-zero on any violation. It reads a generated `rules.json` snapshot, so it runs without the repository and without the TOML registry.
- **Restricted rules as review notes.** Restricted conditions remain prose, so the checker lists restricted constructs only on request (`--restricted`), as items for manual review, and never fails on them.
- **Freshness.** The skill directory is generated by `python -m simplified_python.skill` and verified by `--check`, a test, and CI. The skill records the rule-set version.

Explicitly **not** in this change: checking restricted-rule conditions in code, autofix, a published package or install command, severity levels, and restrictions on builtins or library use.

## Capabilities

### New Capabilities

- `subset-skill`: the generated agent skill: required content, size discipline, self-containment, versioning, and freshness.
- `subset-checker`: the banned-construct checker: what it detects, how it reports, exit codes, and its relationship to restricted rules and the Python version.

### Modified Capabilities

None.

## Impact

- **New files:** `skills/simplified-python/` (generated), `skills/SKILL.template.md` (hand-written source), `src/simplified_python/check.py`, `src/simplified_python/skill.py`, tests.
- **CI:** one added step, `python -m simplified_python.skill --check`.
- **Registry code:** `contains_construct` is refactored over a new location-yielding matcher shared with the checker, so the checker and the registry's example tests cannot disagree about what a rule matches.
- **Python version:** the checker needs Python 3.14 to parse 3.14 syntax and to know every node type; it says so and exits with a distinct code otherwise.
